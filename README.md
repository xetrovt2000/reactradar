# ReactRadar – Testversion

Prüft YouTube-Videos vor einer Twitch-Reaction auf Stellen mit Bann-Risiko (Nacktheit auch im Hintergrund,
Slurs, NS-Gesten, Hassrede) – mit Zeitstempeln, Einstufung und Empfehlung.

**Testseite:** https://xetrovt2000.github.io/reactradar/

- Beispiele ansehen: ohne Anmeldung, ohne Schlüssel.
- Eigene Videos prüfen: mit eigenem, kostenlosem Gemini-Schlüssel aus Google AI Studio. Der Schlüssel bleibt im
  Browser (localStorage) und wird nur an die Gemini-API von Google gesendet.
- Keine Tracker, keine Cookies, kein eigener Server.

Testprojekt, keine Garantie: Die KI kann Stellen übersehen oder falsch einordnen.
